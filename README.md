# Bloodiest — брендовий лендінг (завдання)

Що здавати:
1. **Промт** — `1_Промт.md`
2. **Скріни того, що згенерував ШІ** — `2_Скріни_ШІ/` (десктоп + мобільна чернетка)
3. **Фінальний лендінг** — `3_Фінальний_лендінг/`
   - `лендінг-десктоп.png` і `лендінг-десктоп.pdf` — повна сторінка
   - `мобільна-перший-екран.png`, `лендінг-мобільна-повна.png` — мобільна версія

Секції (за ієрархією): шапка → hero з CTA → для кого (біль) → про бренд → смаки → склад/ефект → відгуки → спецпропозиція Night Pack → FAQ → фінальний CTA (підписка −10%) → футер з контактами.

Канва: імпортуйте `лендінг-десктоп.png` (або окремі секції) у Canva (дизайн «Вебсайт»), за потреби підправте тексти, натисніть **Preview** → іконка телефона й зробіть скрін мобільної версії.

Вихідники: `src/landing.html` (фінал), `src/ai-draft.html` (чернетка ШІ), `src/mobile-preview.html` (рамка телефона), `assets/` (лого й банки з референсів).
